# KeyMacro 🎮

背景遊戲按鍵發送器，類似 X-Mouse Button Control。支援觸發熱鍵、組合鍵、頻率設定，可對背景視窗精確發送指令。

## 功能

- 🎯 **觸發熱鍵** — 設定一個按鍵，按住即觸發巨集
- ⌨️ **巨集序列** — 支援單鍵、組合鍵（Ctrl+C、Shift+A、Alt+F4 等）
- 🔁 **頻率控制** — 可調按鍵按住時間、間隔、重複次數
- 🖥️ **背景發送** — 指定目標視窗，遊戲在背景也能接收指令
- ⏹️ **隨時中斷** — F2 熱鍵可立即停止發送

## 安裝

### 前置需求

```bash
pip install pynput pywin32
```

### 執行

```bash
python main.py
```

> ⚠️ 需要 Windows 作業系統

## 使用方式

1. 設定 **觸發熱鍵**（如 `f1`）
2. 輸入 **巨集序列**，用逗號分隔，例如：
   ```
   ctrl+c, a, b
   ```
3. 設定 **按鍵按住時間**、**間隔**、**重複次數**
4. 選擇 **目標視窗**（留空表示前景視窗）
5. 點擊 **啟動監聽**
6. 切換到遊戲，按住熱鍵即可觸發

## 巨集格式

| 範例 | 說明 |
|------|------|
| `a, b, c` | 依序發送 A → B → C |
| `ctrl+c` | Ctrl+C（複製） |
| `shift+a` | Shift+A（大寫 A） |
| `alt+f4` | Alt+F4（關閉視窗） |
| `space, enter` | 空白鍵 → Enter |
| `f1, f2, f3` | F1 → F2 → F3 |
| `win+d` | Win+D（顯示桌面） |

## 組合鍵支援

可用的修飾鍵：`ctrl`、`shift`、`alt`、`win`

## 設定說明

| 參數 | 說明 | 預設值 |
|------|------|--------|
| 按鍵按住時間 | 每個按鍵按住的毫秒數 | 50ms |
| 按鍵間隔 | 每個按鍵之間的延遲 | 100ms |
| 重複次數 | 巨集執行幾次 | 1 |
| 啟動前延遲 | 觸發後等待多久開始發送 | 500ms |

## 熱鍵

- **自訂觸發熱鍵** — 按住時觸發巨集
- **F2** — 隨時中斷發送

## 技術說明

使用 Windows `PostMessage` API 搭配 `WM_KEYDOWN` / `WM_KEYUP`，可向背景視窗精確發送按鍵訊息，不會被其他應用程式干擾。
